# Contributing

You do not need to be an expert. Start small and ask questions.

## Ways to help
- Fix bugs or add features to this site or to any listed project
- Improve the docs
- Test projects and report problems
- Share ideas and designs

## Steps
1. Fork this repository and clone your fork.
2. Make a branch: `git checkout -b my-change`
3. Run the site: `npm install`, then `npm run dev`. The README explains the Supabase setup.
4. Make your change, commit it and push it to your fork.
5. Open a pull request. Say what you changed and why.

## Before you open a pull request
- `npm run build` works.
- You did not commit passwords, keys or `.env` files.
- The change does one thing.

## Page text
All text is in `src/text/`. You can change it without touching other files.

## Adding a project
Sign in on the site and choose **Add a project**. An admin will review it.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
