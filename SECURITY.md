# Security

If you find a security problem in this site or in a listed project, tell us in private. Do not open a public issue.

- Use **Report a vulnerability** in the Security tab of the repository, or write to an owner of https://github.com/iist-oss.
- Say what you found, how to repeat it and what harm it could do.

Never commit passwords, API keys or the Supabase service role key. If you did by mistake, tell a maintainer so the key can be replaced.
